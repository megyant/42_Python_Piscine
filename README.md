# Python Piscine

This repository consists of a set of smaller projects to introduce programming to python and object-oriented programming. There are different modules ranging from 0 to 11, each composed of several different exercises, from basic to advanced.

## Module 00

This module contains 7 exercises. Here we learn about how defining functions in python works, about how to work with strings and integers and how to use some functions in python such as print() ant input().

## Module 01

This module contains 6 exercises. Here we learn about how to work with classes and subclasses, allowing for the creation of more complex programs.

## Module 02

This module contains 6 exercises. It focus on teaching the try / except / finally blocks, what exceptions are, how to build custom exceptions and how to raise them.  

## Module 03
This module contains 7 exercises. The focus is to learn how to use the sys library with the sys.argv command in order to get input from the command line in the terminal. It also introduces other concepts such as tuples, unions, how to use set() and get() and what keys and values are in dictionaries. Finally it introduces the concept of generators in python.  

## Module 04
This module contains 5 exercises. It teaches how to open, read, write and close files in python using both built-in functions and the sys library (stdin, stdout and stderr).
